AI 피드백은 사용자의 Google Gemini API 키로 직접 호출합니다. 키는 이 브라우저에만 저장되고, 저희 서버에는 전송되지 않습니다.

  1. Google AI Studio에서 무료로 키 발급 (구글 계정만 있으면 됨)
  2. 발급받은 키를 아래에 붙여넣기
왜 API 키를 직접 넣어야 하나요?

저희가 AI 비용을 대신 내면 서비스 가격이 올라가요. 대신 키를 직접 연결하시면 무료 등급만으로도 충분히 쓸 수 있고, 그만큼 서비스는 더 저렴하게 유지됩니다. 키는 브라우저에만 저장되고 어디에도 전송되지 않아요.
